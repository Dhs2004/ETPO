# Initial skill attribution

- ALFWorld: adapted from [SkillZero](https://github.com/ZJU-REAL/SkillZero), revision `1980cd589036ec9f04c64749bbd317a8dd0eef7a`, Apache-2.0. The task alias `pick_and_place_simple` is included.
- WebShop: general guidance from [SDAR](https://github.com/ZJU-REAL/SDAR), revision `308153bb5f7d63cd57f301f432d616a072220e1b`, Apache-2.0.
- ScienceWorld: condensed and adapted from [SkillNet](https://github.com/zjunlp/SkillNet), revision `358ec824577e8a5aa6857c0eff268e492703606b`, MIT. Adaptations remove assumed object states and condition actions on observations.
- Sokoban: method-specific guidance for the text action interface. The environment uses [gym-sokoban](https://github.com/mpSchrader/gym-sokoban), MIT.

Upstream license files are retained in this directory. The JSON mapping files select fixed prompt text; they contain no evaluation results or rollout records.
