# ScienceWorld initial skills

## When to use
Use for text-based science tasks involving objects, state changes, measurements, experiments, or classification.

## Workflow
1. Read the exact task description and identify the target object or substance, required state or observation, and completion conditions.
2. Inspect the current room and inventory. Navigate to a relevant room and inspect containers before assuming a needed object is absent.
3. Use only action/object combinations supported by the current observation. Keep track of objects moved, devices activated, and effects already observed.
4. For state-change tasks, acquire or locate the target, use an appropriate container or device, and observe its state after the action. Focus on the requested target when the task requires it.
5. For measurements and comparisons, collect actual observations with the appropriate instrument. For experiments, change the required variable and inspect the result rather than assuming the expected outcome.
6. Re-read the goal after intermediate progress and verify that all required conditions have been met.

## Pitfalls
Do not infer success from plausible scientific reasoning alone: the environment must reflect the required state. Use exact object references and disambiguate when asked. Avoid repeating ineffective actions without new observations. Do not terminate based only on a partial score.
